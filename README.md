# FitTrack-CRM
A full-stack Fitness CRM &amp; Subscription Portal built with PHP &amp; MySQL. Features automated recurring billing, member management, trainer scheduling, attendance tracking, and role-based dashboards for admins and staff.

Project Title: Fitness CRM & Subscription Portal

Short Description:
A full-stack gym management solution built with PHP and MySQL to automate member subscriptions, scheduling, and billing operations.

📖 Overview
This project is a centralized CRM and subscription portal designed to streamline gym operations by replacing manual processes with automated workflows. It solves common pain points such as scheduling conflicts, missed payments, and fragmented records. The system offers specific portals for Administrators, Staff, and Members to enhance operational efficiency and user experience.

🚀 Key Features
For Administrators:
-- Dashboard: View real-time KPIs, active members, and daily earnings.
-- Member Management: Handle registrations, membership tiers, and status tracking.
-- Staff & Trainer Management: Assign trainers, manage availability, and book sessions.
-- Reporting: Automated reports for revenue and attendance to reduce reconciliation time.

For Staff:
-- Daily Operations: Tools for appointment scheduling and marking attendance.
-- Member Support: Access to member profiles for quick assistance.

For Members (Self-Service Portal):
-- Online Registration: Fast sign-up with digital waivers and photo uploads for ID cards.
-- Subscription Management: Select plans, view payment history, and manage renewals.
-- Transparency: View class bookings and trainer notes at any time.

🛠️ Tech Stack
-- Frontend: Responsive HTML/CSS/JS with Bootstrap framework.
-- Backend: PHP for server-side logic and API handling.
-- Database: MySQL relational database for storing members, payments, and schedules.
-- Security: Implements session management, password hashing, and input validation.

⚙️ Architecture & Development
-- Pattern: Follows an MVC-like separation for maintainability.
-- Environment: Developed and tested locally using XAMPP/MAMP.
-- Integrations: Designed to support payment gateways and optional biometric scanners.

🔮 Future Scope
-- Mobile App: Native apps for booking and notifications.
-- AI Analytics: Churn prediction and personalised recommendations.
